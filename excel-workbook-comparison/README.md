# Excel workbook comparison (values only)

`excel_workbook_comparison.ipynb` compares two Excel workbooks sheet by sheet and cell by cell on
**cached values, not formulas**, and writes a third workbook listing every difference.

## Use it

```bash
pip install openpyxl pandas
jupyter notebook excel_workbook_comparison.ipynb
```

Set three paths in section 2 and run all cells:

```python
FILE_A = "workbook_a.xlsx"
FILE_B = "workbook_b.xlsx"
OUTPUT_FILE = "differences.xlsx"
```

Section 7 runs a self-test on generated workbooks, so you can confirm it works before pointing it at
real files.

## Output

| Sheet | Contents |
|---|---|
| `Summary` | Verdict, totals by difference type, every option used, warnings |
| `Sheet Inventory` | Every sheet in either workbook: matched, only-in-A, only-in-B, chart sheet, used range, diff count |
| `Cell Differences` | One row per differing cell — sheet, cell ref, both values, both types, numeric delta, % change |
| `<sheet>` tabs | Per-sheet breakdown, when `per_sheet_tabs=True` |

Colour coding: yellow *value changed*, orange *type changed*, green *added in B*, red *removed in B*.

## Comparison rules

All configurable in section 2:

| Option | Default | Effect |
|---|---|---|
| `abs_tolerance` / `rel_tolerance` | `1e-9` / `0.0` | Float tolerance — absorbs calculation noise |
| `round_numbers_to` | `None` | Round both sides to N decimals first |
| `trim_whitespace` | `True` | `"  abc "` equals `"abc"` |
| `collapse_whitespace` | `False` | `"a    b"` equals `"a b"` |
| `case_insensitive_text` | `False` | `"Total"` equals `"total"` |
| `blank_equals_empty_string` | `True` | Empty cell equals `""` |
| `numeric_strings_as_numbers` | `False` | Text `"1,234.50"` equals number `1234.5` |
| `ignore_time_component` | `False` | Compare dates, ignore times |
| `only_sheets` / `ignore_sheets` / `sheet_map` | — | Restrict or re-map sheet pairing |
| `include_hidden_sheets` | `True` | Include hidden sheets |
| `per_sheet_tabs` | `False` | Add a tab per differing sheet |
| `max_diffs_per_sheet` / `max_total_diffs` | 100k / 500k | Safety valves; truncation is flagged in the report |

## Limits worth knowing

- **Cached values must exist.** openpyxl reads the value Excel stored on the last save; it does not
  calculate. Workbooks generated by a script often have no cached values, so formula cells read as
  blank. The notebook detects this and warns — re-save the file in Excel to fix it.
- **Matching is positional** (`A1` vs `A1`). Inserting a row shifts every cell below it and will be
  reported as many differences. That is correct for a cell-over-cell diff; row-keyed reconciliation
  needs a join on a key column instead.
- **Not compared:** charts, chart sheets, images, pivot caches, formatting, number formats, column
  widths, comments, macros, defined names.
- **`.xls` / `.xlsb` are not supported** — convert to `.xlsx` first.

Verified against ~1.2M cells (3 sheets × 5,000 rows × 40 columns per side) in about 9 seconds.
